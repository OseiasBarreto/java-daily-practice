# Fuel Efficiency Tracker

![Java](https://img.shields.io/badge/Language-Java-orange?style=for-the-badge&logo=java)

O **Fuel Efficiency Tracker** é um programa em Java que lê a distância percorrida e a quantidade de combustível gasta, calcula a eficiência de combustível (KM/L) e exibe o resultado no console.  
É um exercício para treinar **entrada de dados, operações matemáticas, tratamento de exceções e exibição de resultados**.

---

## 🚀 Como Executar

### 📋 Pré-requisitos
- Java JDK 8 ou superior
- IDE (IntelliJ IDEA, Eclipse, VS Code)

### 🔧 Execução

1. Abra a classe `FuelEfficiencyTracker.java` dentro do pacote `fundamentals.fuelefficiencytracker`.
2. Execute o arquivo com `main`.
3. Siga as instruções no console, inserindo a distância percorrida e a quantidade de combustível gasta.

O programa calculará automaticamente a eficiência de combustível em **KM/L**.
