# Employee Manager

![Java](https://img.shields.io/badge/Language-Java-orange?style=for-the-badge&logo=java)

O **Employee Manager** é um programa em Java que permite cadastrar funcionários, armazenar seus dados (ID, nome e salário) e aplicar aumentos salariais por porcentagem.  
É um exercício para treinar **listas genéricas, entrada de dados, loops, validação de dados e manipulação de objetos em Java**.

---

## 🚀 Como Executar

### 📋 Pré-requisitos
- Java JDK 8 ou superior
- IDE (IntelliJ IDEA, Eclipse, VS Code)

### 🔧 Execução

1. Abra a classe `Program.java` dentro do pacote `fundamentals.EmployeeManager.application`.
2. Execute o arquivo com `main`.
3. Siga as instruções no console para:
   - Registrar funcionários (informando ID, nome e salário)
   - Aplicar aumento salarial a um funcionário pelo ID
   - Listar todos os funcionários cadastrados com seus salários atualizados

O programa valida automaticamente IDs duplicados e exibe mensagens apropriadas.
